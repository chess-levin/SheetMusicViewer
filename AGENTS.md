# Project agent instructions

These instructions apply to ChatGPT, Codex, and every other agent working in
this repository.

## Dependency and license policy

- The project's license is [MIT](SheetMusicViewer/LICENSE). Only add, update,
  vendor, or redistribute a component when its license is compatible with the
  MIT license and the component's redistribution requirements can be met.
- Verify the exact license and its obligations before changing any direct,
  transitive, build-time, runtime, or bundled dependency. Do not infer a
  license solely from a package name, repository, or an unverified web page.
- Treat unknown, proprietary, copyleft, fee-based, or additional contractual
  terms (including package EULAs) as incompatible until the user explicitly
  reviews and approves them.
- When a dependency or distributable component changes, update the applicable
  SBOM and third-party notices so that all required copyright and license texts
  are distributed with the relevant artifact.

## Documentation check

- For every change, assess whether [README.md](README.md) must be updated.
- Update the README whenever user-facing behavior, prerequisites, commands,
  build outputs, distribution contents, configuration, dependencies, or
  licensing information changes.
- If no README update is needed, state that this check was performed in the
  final handoff.
